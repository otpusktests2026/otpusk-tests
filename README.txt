# Отпуск вам к лицу — сайт-каталог тестов

Это стартовая версия статического сайта. Главная страница — `index.html`, тест находится в `tests/otdykh.html`.

## Важно перед публикацией
В тесте сейчас стоит рабочая демонстрационная механика и черновые формулировки. Перед публичным запуском нужно сверить вопросы, варианты и результаты с финальной редакцией, которую выберет владелица канала.

## Публикация через GitHub Pages
1. Зарегистрируйтесь на https://github.com
2. Нажмите `Sign up` и создайте аккаунт по электронной почте.
3. После входа нажмите `New repository`.
4. Название репозитория: `otpusk-tests`.
5. Выберите `Public`, затем `Create repository`.
6. Нажмите `Add file` → `Upload files`.
7. Распакуйте архив и загрузите содержимое папки `otpusk-tests-site` (файл `index.html` и папку `tests`, не сам ZIP).
8. Нажмите `Commit changes`.
9. Откройте `Settings` → `Pages`.
10. В разделе `Build and deployment` выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`, затем `Save`.
11. Через некоторое время GitHub покажет адрес опубликованного сайта в разделе Pages.

## Добавление нового теста
Создайте новый HTML-файл в папке `tests`, затем добавьте карточку-ссылку на него в `index.html`.
